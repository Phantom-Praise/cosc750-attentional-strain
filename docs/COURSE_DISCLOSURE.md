# Course-use disclosure

Codex assisted with experiment orchestration, custom model wrappers, validation
tests, reporting, documentation, and repository organization. Predictor choices
and experimental directions were discussed with the student. The student is
responsible for reviewing, understanding, verifying, and disclosing this work.

Standard learners, preprocessing, calibration, selection, and metrics are reused
from scikit-learn. The histogram classifier is custom code based on the supplied
course examples. Archived exploratory work also uses mord and imbalanced-learn,
whose notices remain with that work. No claim is made that all algorithms were
independently implemented by the student.

Earlier results informed the later exploratory searches. The reported small
differences are not independently confirmed gains, clinical validation, or proof
of algorithmic novelty. Preserve this disclosure when preparing the cumulative
paper and recording, as required by the supplied course template.
