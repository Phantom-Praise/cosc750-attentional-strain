# Recorded reference outputs

Generated by `python reproduce.py --proposed` on November 1, 2026. These files
record results for checking a fresh reproduction; the program does not read them
to train models, select settings, or produce scores.

- `baseline_table.*`: five shared held-out splits for all five baseline models.
- `proposed_validation_table.*`: the separate exploratory nested-validation
  comparison of ordinary and calibrated SVM. These are not test-set scores.
- `*_per_class.csv`: class-wise precision, recall, F1 and error counts.
- `.tex` tables require the `booktabs` LaTeX package.
- `reproduction_manifest.json`: execution environment and source/data hashes.
  Its recorded command describes the original recording run, not the fresh clone.

Timing depends on hardware; compare predictive metrics and selected settings,
not exact seconds. Holdouts overlap and fold SD is not a confidence interval.
All 25 baseline and six proposed/reference outer prediction sets matched the
earlier experiments exactly in the workspace verification.

Start with [baseline_table.md](baseline_table.md), then read the separate
[calibrated-SVM validation table](proposed_validation_table.md).
